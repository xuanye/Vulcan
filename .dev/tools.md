# Tools

## Required
- .NET SDK 10.0+
- PowerShell (pwsh)

## Recommended
- Visual Studio 2022 / JetBrains Rider / VS Code

## Optional
- eza (better ls)
- zoxide (smart cd)
- fzf (fuzzy finder)

## Notes
These tools are optional and should not be required for scripts or CI/CD.
All build/test commands use standard `dotnet` CLI.
